## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or bun

### Installation
```bash
git clone https://github.com/deepakkonijeti5886-Ui-Design/deepak-konijeti-portfolio.git
cd deepak-konijeti-portfolio
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) or [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
